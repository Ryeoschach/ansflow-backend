# K8s 集群扩容手册

## 概述
当集群资源不足时，我们需要进行 Node 扩容。AnsFlow 提供了标准的自动化扩容流水线，流水线 ID 为 `pl-scale-node-001`。

## 操作步骤
1. 登录 AnsFlow，进入【流水线】页面。
2. 搜索 `pl-scale-node-001`。
3. 点击【执行】，在弹出的参数中输入目标节点数量 `node_count`。
4. 确认执行后，系统将自动调用 Terraform 扩容云端主机并将其加入 Kubernetes 集群。

## 常见报错排查
如果流水线报错 `Timeout waiting for node to join`：
- **原因**：通常是因为新节点的安全组没有放行 K8s 内部通信端口 (6443/10250)。
- **解决**：检查主机管理中的云安全组设置，确保 10250 端口对 Master 节点放行。
